# thymio-obstacle-avoidance
CSPB476 Robotics Project - Obstacle Avoidance in Webots

## Overview
This project implements obstacle avoidance and goal navigation for a Thymio robot in Webots.

## Features
- Reactive obstacle avoidance
- Lidar-based navigation
- Odometry + compass localization
- Goal pose alignment
- Multi-mode control (AVOID, GO_TO_POSE, ENTER_GOAL, STOP)
